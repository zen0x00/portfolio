# Aman Kumar Matta — Portfolio

A static, content-first systems engineering portfolio built with Astro.

## Stack

- Astro 7 with strict TypeScript
- Tailwind CSS 4 through the official Vite integration
- CSS-generated project artwork and motion
- Static output suitable for Cloudflare Pages, Vercel, or any static host

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

Portfolio content is defined in `src/data/portfolio.ts`; the page is composed in
`src/pages/index.astro`.
